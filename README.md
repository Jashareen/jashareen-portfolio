# Jashareen — Personal Portfolio

Responsive dark-theme portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy on Render (free static site)
1. Push this folder to a GitHub repository.
2. In Render, choose **New + → Static Site**.
3. Connect the portfolio repository.
4. Leave the build command empty and set the publish directory to `.`.
5. Deploy.
